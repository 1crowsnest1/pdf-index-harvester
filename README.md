# PDF Index Harvester

Harvest PDFs linked from any HTML index page, then extract embedded images and generate 8×8 contact-sheet thumbnails for rapid visual browsing.

> **Please be respectful of the source.**  
> This tool is intended for personal research and archival study.  
> Check the site’s terms of service, keep the download delay ≥ 1 s, and do not redistribute harvested content unless you have permission.

## Features

- Scrapes any HTML index page for `.pdf` links and downloads missing files
- Skips already-downloaded files (resumable)
- Configurable polite delay between requests
- Extracts every embedded raster image from each PDF
- Builds dark-themed 8×8 (64-page) contact sheets as JPEG
- Can run download-only or extract-only

## Installation

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
python3 -m pip install -r requirements.txt
```

## Usage

You **must** supply the index URL (or edit the placeholder in the script):

```bash
python pdf_index_harvester.py \
  --index-url "https://example.com/path/to/index.html"
```

Useful options:

```bash
# Only download PDFs (skip image extraction)
python pdf_index_harvester.py --index-url "..." --skip-extract

# Only process already-downloaded PDFs
python pdf_index_harvester.py --skip-download

# Custom locations + slower crawl
python pdf_index_harvester.py \
  --index-url "https://example.com/path/to/index.html" \
  --pdf-dir   ./my_archive \
  --image-dir ./images \
  --grid-dir  ./sheets \
  --delay 2.5
```

| Flag | Default | Meaning |
|------|---------|---------|
| `--index-url` | `https://example.com/...` (placeholder) | HTML page that links to PDFs |
| `-p / --pdf-dir` | `./pdf_archive` | Where PDFs are stored |
| `-o / --image-dir` | `./visual_catalog/extracted_images` | Extracted images |
| `-g / --grid-dir` | `./visual_catalog/contact_sheets` | Contact-sheet JPEGs |
| `--delay` | `1.0` | Seconds between downloads |
| `--skip-download` | off | Skip Phase 1 |
| `--skip-extract` | off | Skip Phase 2 |

## Output layout

```
pdf_archive/                      # harvested PDFs
visual_catalog/
  extracted_images/               # every embedded image
    <pdf>_p<page>_fig<n>.png
  contact_sheets/                 # 8×8 thumbnail grids
    <pdf>_contact_sheet_1.jpg
```

## Limitations

- Only extracts **embedded** raster images (`page.get_images()`).  
  Vector drawings or scanned full-page figures that are not stored as separate XObjects will not appear.  
  For more aggressive figure detection (geometry scoring, text masking, etc.) see the companion project `pdf-image-extract`.
- Contact sheets are purely visual aids; they do not contain searchable text.
- Network errors on individual PDFs are logged and skipped; the rest of the run continues.
